# КЛЮЧЕВЫЕ КОМПЕТЕНЦИИ

## 1. Сетевые технологии и инженерия Cisco:
    ◦ Маршрутизация и коммутация: Маршрутизаторы Cisco (серий 2801, 2811, 2821), коммутаторы
        (2960, 3560, 3750). Сегментация сетей на изолированные broadcast-домены (VLAN 802.1Q, Trunk).
    ◦ Протоколы и технологии: Магистральные агрегированные каналы EtherChannel (LACP, PAgP)
        между коммутаторами Cisco 3750 (включая стек 3750 / StackWise), резервирование
        и защита от петель (STP, Rapid-PVST+, MSTP, Root Bridge, балансировка корней
        по VLAN: root primary / root secondary).
        Динамическая маршрутизация (OSPF с MD5, Multi-Area OSPF, EIGRP, RIP, Redistribution OSPF ↔ EIGRP).
        Резервирование шлюзов (HSRP, виртуальный IP, трекинг аплинков). Стык с провайдером (eBGP).
        Двухстековая маршрутизация (IPv6, OSPFv3).
    ◦ Безопасность и службы: Управление трафиком через списки доступа (ACL), защита портов
        (Port Security, sticky MAC, violation restrict/shutdown), DHCP Snooping (trust/untrust).
        Настройка NAT/PAT Overload, Static NAT (проброс портов).
        Конфигурирование туннелей с шифрованием и сжатием (IPsec, OpenVPN, GRE, OpenSwan).
    ◦ Беспроводная сеть и телефония: Точки доступа Cisco (1100, 1200, 1300), настройка мостов,
        автономные и облегчённые архитектуры (WLC/AP, CAPWAP). Администрирование АТС
        (IP-телефония, маршрутизация вызовов, тарификация).
    ◦ Удалённая работа и инструменты: Подключение к оборудованию через VPN (OpenVPN/IPsec),
        SSH-туннели. Документирование изменений.

## 2. Администрирование операционных систем и инфраструктуры:
    ◦ Windows Server (2003–2012 R2): Полный цикл администрирования: Active Directory (AD), групповые
        политики (GPO), DNS, DHCP, Terminal Server, Certificate Server.
    ◦ Linux (Ubuntu, Astra, Debian и др.): Построение межсетевых экранов и маршрутизаторов (Iptables+Syslog),
        кэширующих прокси-серверов (Squid+Sarg+Apache), корпоративной почты (Postfix, FetchMail, Procmail),
        файловых серверов в Windows-окружении (Samba, Winbind, Krb5), веб-серверов (LAMP) и FTP (VsFtpd).
    ◦ Виртуализация: Развертывание тестовых стендов и сред виртуализации на базе VirtualBox / Qemu,
        PhpVirtualBox (управление через веб-интерфейс, автозапуск/бэкапирование/управление).
        Лабораторные стенды: Packet Tracer.

## 3. Автоматизация, программирование и базы данных:
    ◦ Автоматизация Linux: Написание модульных скриптов на Bash для миграции, обслуживания и восстановления
        инфраструктурных сервисов (включая работу с Git, логирование, обработку ошибок и поддержку режима
        симуляции и тестирования).
    ◦ Автоматизация Windows: Разработка системных скриптов автоматизации на CMD/Batch.
    ◦ Базы данных: Проектирование реляционных СУБД (MS SQL Server, MySQL, PostgreSQL), (Apache+PHP+MySQL).
        Навыки приведения БД к 3-й нормальной форме (3НФ), построения ER-моделей, связей 1:∞,
        первичных/внешних ключей и каскадных правил для обеспечения целостности данных.
    ◦ Языки программирования: HTML, JavaScript, PHP, Python, C++, Delphi, VBA, SQL.

## 4. Применение LLM в системном анализе и моделировании:
    ◦ Генерация и верификация конфигураций Cisco (OSPF, BGP, ACL, NAT) с помощью LLM,
        с последующей проверкой в лабораторном стенде.
    ◦ Анализ `show`-выводов, логов и тикетов: автоматизация разбора инцидентов
        и подготовка черновиков RCA.
    ◦ Совместная разработка и пересборка расчётных моделей (5+ итераций) с контролем допущений.
    ◦ Работа с неполными данными: построение моделей при неизвестной структуре процесса.
    ◦ Интеграция ИИ в цикл «гипотеза → расчёт → проверка → документ».
